##College Club Membership Portal##

A menu-driven application developed using C programming to manage college club memberships.

Features

- Student registration
- Duplicate student ID checking
- View membership details using student ID
- Display all registered members
- View information about available clubs
- Remove an existing membership
- Display members club-wise
- Save and load membership records using file handling
- Password-protected access to the complete membership list

Available Clubs

1. Coding Club
2. Robotics Club
3. Electronics Club
4. Cultural Club
5. Sports Club

Technologies Used

Language: C

Concepts applied:

- Structures and arrays
- Functions and modular programming
- Loops and conditional statements
- String handling
- File handling using "fopen()", "fprintf()", "fscanf()", and "fclose()"

How to Run

1. Download "main.c" from this repository.
2. Open it in Code::Blocks or another C compiler.
3. Compile and run the program.
4. Follow the menu options displayed in the terminal.

Data Storage

The program uses "student.txt" to store membership records between program executions.

Learning Outcomes

This project helped me practise modular programming, structures, arrays, string handling, record management, and file handling in C.
